# COACH GHOST - Plataforma Full Stack Deportiva

Plataforma deportiva de alto rendimiento inspirada en el ecosistema **Nike Training**, integrando arquitectura **MERN + IA** (React, Express, MongoDB e Inteligencia Artificial Biomecánica).

## 🚀 Características Principales
- **Landing Nike Training:** Estética deportiva oscura con contrastes neón (#00FF88).
- **Catálogo de Suscripciones:** Planes Jugador, Escuela y Familiar en pesos colombianos (COP).
- **IA Recomendador Biomecánico:** Prescripción técnica adaptada a la posición del atleta (Delantero, Defensa, Medio, Arquero).
- **Match de Escuelas de Fútbol en Bogotá:** Geolocalización y recomendación por localidades (Suba, Kennedy, Engativá, Chapinero, Bosa, Usaquén).
- **Panel Administrativo Protegido:** Autenticación con JWT (dmin / ghost2024), gestión de atletas y exportación de registros a CSV.
- **Arquitectura de Despliegue:** Preparado para Backend en Render y Frontend en GitHub Pages.

## 🛠️ Tecnologías
- **Frontend:** React, Vite, Axios, Lucide Icons, CSS3.
- **Backend:** Node.js, Express, JWT, Cors, Dotenv, Mongoose.
